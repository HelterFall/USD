# USD — курсы валют и стоимость золота

Python-скрипт получает официальный курс USD/RUB и CNY/RUB из XML API Банка России, запрашивает спотовую цену золота XAU в USD за тройскую унцию и рассчитывает стоимость одного грамма золота в рублях.

## Источники

- Курсы валют и дата котировки: [Банк России](https://www.cbr.ru/development/sxml/)
- Спотовая котировка золота: [Gold API](https://api.gold-api.com/price/XAU)

Цена золота в RUB/г рассчитывается по формуле: цена XAU в USD за тройскую унцию × курс USD/RUB ÷ 31,1034768. Это расчётная спотовая цена, не цена продажи ювелирного изделия и не гарантированная цена покупки металла.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python main.py
```

После запуска рядом со скриптом появится `exchange_rates.xlsx`. Каждый запуск добавляет новую строку в историю. Время проверки записывается в часовом поясе `Europe/Moscow`, а дата котировки ЦБ сохраняется отдельно.

Чтобы задать другой часовой пояс или путь к файлу:

```bash
TIMEZONE=Europe/Moscow OUTPUT_FILE=exchange_rates.xlsx python main.py
```

В Windows PowerShell:

```powershell
$env:TIMEZONE="Europe/Moscow"
$env:OUTPUT_FILE="exchange_rates.xlsx"
python main.py
```

Для запуска требуется подключение к интернету. Если API недоступен или изменит формат ответа, скрипт сообщит об ошибке и не запишет фиктивные значения.
